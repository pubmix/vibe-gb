# openai-flash-cart

GBDK-2020 Game Boy project.

The ROM displays:

```text
ModRetro logo splash with fade
OpenAI logo with Powered by Codex
Terminal-style your access key is: screen
```

Music is generated in `src/uge_song.c` and played through hUGEDriver.

Build:

```powershell
.\examples\openai-flash-cart\game\build.ps1
```

Run:

```powershell
.\examples\openai-flash-cart\game\run.ps1
```

Output:

```text
outputs\openai-flash-cart.gb
```
